## 1. 先明确在插值什么

本节的a、b都是单位四元数，表示两个完整朝向；不是待旋转向量p。结果也是朝向四元数，再用已有TransformDirection观察right/up/forward。坐标约定不变：+X右、+Y上、+Z前；Y+90°使+Z→+X。

教材：[《3D Math Primer》作者在线版8.5.12](https://gamemath.com/book/orient.html)的实用Slerp公式为：

```text
Slerp(a,b,t) = sin((1-t)ω)/sin(ω) * a + sin(tω)/sin(ω) * b
cos(ω) = Dot(a,b)
```

这里乘号是标量乘四个分量，加号是分量相加，**不是Hamilton积**。ω是四维单位球面上两个四元数的夹角；选择最短路径后，对应的物体旋转角为2ω。不要把ω当成物体角度，再额外除一次2。

本节接口将有限t限制到[0,1]：0取起点，1取终点。输入保证单位四元数，Normalized单独保证非零有限输入；不扩展零输入异常策略。

## 2. TODO 13.1与13.2 点积和归一化

文件：`MathLibrary/Quaternion.cs`。

```text
Dot(a,b) = ax*bx + ay*by + az*bz + aw*bw
length(q) = sqrt(x²+y²+z²+w²)
Normalized(q) = (x/length,y/length,z/length,w/length)
```

四元数不是三维方向，w必须参与。点积返回一个数；此前Multiply返回另一个四元数，两者用途不同。归一化必须用原来的同一个长度处理四个分量，不能只归一化xyz。

## 3. TODO 13.3 Nlerp 最短路径归一化线性插值

普通分量Lerp：`r=(1-t)*a+t*b`。它沿四维空间中的线段混合，通常会落到单位球内部，不能直接当单位旋转四元数使用。因此再执行归一化，得到Nlerp。

先处理上一课的q与-q：它们表示同一朝向，但直接混合中点会得到全零。为使四元数代表位于同一半球，若Dot(a,b)<0，则把b的**四个分量**全部取反；这不改变终点朝向，却改变插值路线。

实现顺序：

1. t限制到[0,1]。
2. 点积为负时翻转b。
3. 计算四分量线性混合 `(1-t)*a+t*b`。
4. 返回混合结果的Normalized。

不必新增未经要求的运算符或通用插值框架，直接构造Quaternion即可。a与b的物体相对转角恰好180°时两条最短路径同样长，本节允许按输入符号选择其中一条。

### Nlerp平滑但一般不匀速

以镜头绕Y从0°到120°为例，a=(0,0,0,1)，b=(0,√3/2,0,1/2)。t=0.25时混合得到y=√3/8、w=7/8。归一化不会改变y/w，因此物体角度为：

```text
2*atan2(√3/8,7/8) ≈ 27.795772°
```

若匀速，四分之一进度应为30°。Nlerp中点恰好60°，所以只测中点不能识别速度差异。

纠正一个常见说法：**Lerp/Nlerp不必然“抖动”**。Nlerp在固定端点、符号处理正确时可以连续平滑，只是角速度一般不恒定。抖动还可能来自目标跳变、时间步长或未处理的符号变化。

## 4. TODO 13.4 Slerp 最短路径球面插值

Slerp沿单位球面圆弧而非直线取点，使球面角进度为tω。简短推导：在a、b张成的平面里，把a看作(1,0)、b看作(cosω,sinω)，期望结果为(cos(tω),sin(tω))。

令结果为k0*a+k1*b。比较第二分量得k1=sin(tω)/sinω，代回第一分量得k0=sin((1-t)ω)/sinω。这就是开头的两个权重；对四个分量使用同样权重即可。

实现流程：

1. t限制到[0,1]，计算d=Dot(a,b)。
2. 如果d<0，翻转b全部四分量，并令d=-d。
3. 把d限制到[0,1]，避免浮点误差使Acos越界。
4. 若d>0.9995，退回本节NlerpShortestPath。此阈值是本课工程选择，不是数学定理。
5. 否则ω=MathF.Acos(d)，按公式计算k0、k1。
6. 构造四分量加权结果，并归一化以控制浮点误差。

接近同一朝向时，ω和sinω都接近0，直接除法不稳定，完全相同时会0/0。这个退化不是万向锁。短弧下Nlerp与Slerp很接近，因此允许用Nlerp近似。

固定端点且t随时间线性增加时，精确Slerp为恒定角速度；近角退化分支是近似。若对t做缓入缓出，或每帧改变端点，则不能再直接声称恒速。

### 游戏中的最短路径

从Y+170°转到Y-170°，最短只转20°，中途朝向Y180°。若直接对两个欧拉角数值做普通Lerp，中点是0°，会走340°长路。四元数负点积翻转解决的是代表符号与路线选择，不是给四元数求逆。
