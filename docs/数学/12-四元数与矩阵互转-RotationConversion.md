符号说明：q是单位旋转四元数，p=(vx,vy,vz,0)是待旋转向量的纯四元数形式；q*是共轭，单位情况下也是逆。-q取反全部四个分量，q*只取反xyz；(-q)*的共轭等于-(q*)，故替换q为-q时两处负号抵消。

## 1. 教材依据与约定

《3D Math Primer》作者在线版 [8.7.3–8.7.4](https://gamemath.com/book/orient.html) 给出互转推导，其中的关键恒等式是：

```text
trace(R) = 4w² - 1
```

它连接矩阵的对角线与四元数分量，也是接近 180° 时必须换分支的原因。以下练习按本仓库约定展开：`q=(x,y,z,w)`，Hamilton 积，`v'=R*v` 列向量，+X 右、+Y 上、+Z 前；Y+90° 将 +Z 转向 +X。教材示例的行向量矩阵不能直接按原位置抄入本项目，必须按基向量检查转置和符号。

本节只接收单位四元数、纯旋转矩阵。矩阵左上3×3必须正交且行列式为+1，末行末列为 `(0,0,0,1)`；不含平移、缩放、错切或镜像。不要求实现通用矩阵分解、输入修复、欧拉角互转或插值。

## 2. TODO 12.1：四元数转纯旋转矩阵

文件：`MathLibrary/Quaternion.cs`，方法 `ToRotationMatrix()`。

先复用上一课：分别把局部 right=(1,0,0)、up=(0,1,0)、forward=(0,0,1) 用当前四元数旋转，得到 r、u、f。列向量矩阵的每一列就是对应基向量变换后的结果：

```text
R = [ rx ux fx 0 ]
    [ ry uy fy 0 ]
    [ rz uz fz 0 ]
    [  0  0  0 1 ]
```

这是推荐的第一版实现：复用你已完成的 TransformDirection，不必重新手写一套旋转逻辑。也可用下面的展开式；二选一即可。

```text
R00 = 1-2(y²+z²)   R01 = 2(xy-zw)     R02 = 2(xz+yw)
R10 = 2(xy+zw)     R11 = 1-2(x²+z²)   R12 = 2(yz-xw)
R20 = 2(xz-yw)     R21 = 2(yz+xw)     R22 = 1-2(x²+y²)
```

展开式来自分别计算 `q*(eX,0)*q*`、`q*(eY,0)*q*`、`q*(eZ,0)*q*`，再按列放入矩阵。比如第一列中的 `1-2y²-2z²` 来自 `w²+x²-y²-z²`，利用单位约束化简。

自检：Y+90° 时三列应依次为 -Z、+Y、+X。构造参数虽然逐行书写，数学含义仍是基向量按列排列；这与内存存储顺序无关。输出没有位移，不要把 q.w 写进 M33，M33 固定为1。

## 3. TODO 12.2：纯旋转矩阵转四元数

方法 `CreateFromRotationMatrix(Matrix4x4 rotationMatrix)`。下面的 m00 等对应输入 M00 等属性，索引从0开始。

### 从迹推导，为什么只写一个分支不够

```text
t = m00+m11+m22
  = 3-4(x²+y²+z²)
  = 4w²-1
```

因此 `w=sqrt(1+t)/2`。同时 `m21-m12=4xw`，可以求出 x；y、z 类似。但转180°时 w=0，继续除以4w会除零。这里是提取算法选错分母，不是万向锁：这个朝向本身完全有效。

解决办法：t>0 时求 w；否则选最大的对角项，对应求较大的 x、y 或 z，避免用接近0的分量作分母。必须写全以下四个互斥分支，不需要在结果后强制 w≥0。

| 条件（按顺序判断） | S | x | y | z | w |
| --- | --- | --- | --- | --- | --- |
| t>0 | 2√(1+t) | (m21-m12)/S | (m02-m20)/S | (m10-m01)/S | S/4 |
| 否则 m00≥m11 且 m00≥m22 | 2√(1+m00-m11-m22) | S/4 | (m01+m10)/S | (m02+m20)/S | (m21-m12)/S |
| 否则 m11≥m22 | 2√(1+m11-m00-m22) | (m01+m10)/S | S/4 | (m12+m21)/S | (m02-m20)/S |
| 否则 | 2√(1+m22-m00-m11) | (m02+m20)/S | (m12+m21)/S | S/4 | (m10-m01)/S |

例如 X轴180°矩阵对角线为 `(1,-1,-1)`，t=-1；应走第二行，得到 x=1，其余为0，而不是计算0/0。

四分量可整体变号，因此往返转换不要求恢复原来四个浮点数的符号。要验证单位长度和三根基向量的旋转结果，不能只看 forward，也不能仅做分量相等比较。
