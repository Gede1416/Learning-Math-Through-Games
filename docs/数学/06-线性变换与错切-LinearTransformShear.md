## 教材定义与核心公式

《3D Math Primer》(2nd) Ch 5 将矩阵用于表达线性变换。线性变换保持向量加法与标量乘法：

```text
F(a+b) = F(a) + F(b)
F(sa)  = sF(a)
```

因此线性变换一定保持原点：`F(0)=0`。二维列向量约定下，横向错切矩阵为：

```text
M = | 1  k |
    | 0  1 |

M |x| = |x + k·y|
  |y|   |y      |
```

常见二维线性变换：

```text
缩放：|sx  0 |    旋转：| cosθ  -sinθ |    横向错切：|1  k|
      | 0  sy|          | sinθ   cosθ |              |0  1|
```

---

## 为什么矩阵是一台几何函数

观察错切矩阵的两列：

```text
第一列 (1,0) = M(1,0)：局部 X 基轴保持不变
第二列 (k,1) = M(0,1)：局部 Y 基轴向右倾斜 k
```

任意顶点 `(x,y)` 都可以写成 `x(1,0)+y(0,1)`，所以：

```text
M(x,y) = x·(1,0) + y·(k,1) = (x+k·y, y)
```

这就是“矩阵的列是变换后的基向量”：草叶越高，包含的 Y 基轴越多，横向偏移也越大。

原代码实际对应另一个矩阵：

```text
|1  0|
|k  1|
```

它让 `y'=k·x+y`，即横向位置越靠右，顶点越向上移动；这是纵向错切，不是所需的风吹横向弯曲。

## 为什么本轮使用 Vector2

本轮使用 `Vector2 + Matrix2x2` 是刻意的教学降维：草叶错切只涉及 X/Y 两轴，二维形式能直接观察矩阵第二列 `(k,1)` 如何让 Y 基轴倾斜，避免 Z 轴和坐标系手性分散注意力。

同一变换嵌入三维后为：

```text
|1  k  0| |x|   |x + k·y|
|0  1  0| |y| = |y      |
|0  0  1| |z|   |z      |
```

项目不会继续扩展另一套重复的二维数学库。从下一课“平移与齐次坐标”开始，恢复使用已有 `Vector3`，并引入 `Matrix4x4`，以便和 Unity 等真实游戏引擎的三维变换结构对应。
