## 2. TODO 16.1 创建OBB

文件`MathLibrary/Obb.cs`，类型有：

```text
Center：世界中心C
HalfExtents：局部三个半尺寸hx,hy,hz
AxisX/AxisY/AxisZ：局部X/Y/Z轴在世界中的单位方向u0,u1,u2
```

盒内任意点可写成：

```text
P = C + s0*u0 + s1*u1 + s2*u2
其中 -hx<=s0<=hx，-hy<=s1<=hy，-hz<=s2<=hz
```

CreateFromLocalToWorldRotation只需保留输入Center与HalfExtents，并用已有Quaternion.TransformDirection分别旋转(1,0,0)、(0,1,0)、(0,0,1)得到三个轴。轴是方向，不加入Center；半尺寸也不当成方向向量旋转。

Y+90度时AxisX应为-Z、AxisY为+Y、AxisZ为+X。OBB随着角色转动，局部半尺寸不变，世界轴方向变化。它无需用两个世界Min/Max表示。

## 3. TODO 16.2 投影半径

ProjectionRadiusOnAxis接收测试轴L，L可以不是单位向量。用点积表示沿L的标量投影：

```text
P·L = C·L + s0*(u0·L) + s1*(u1·L) + s2*(u2·L)
```

每个si都可独立取正负边界，所以相对中心的最大投影偏移是：

```text
r(L) = hx*abs(u0·L) + hy*abs(u1·L) + hz*abs(u2·L)
投影区间 = [C·L-r(L), C·L+r(L)]
```

这里的r是区间半宽，不是球半径，也不包含中心投影。abs让轴反向仍得到相同半宽。

例：未旋转半尺寸(2,1,0.5)，沿L=(1,2,3)半径为2+2+1.5=5.5。若整个盒绕Z转45度，沿世界X投影半径为(2+1)*sqrt(0.5)，约2.12132。不是简单沿用原hx=2。

L扩大两倍，中心投影、半径都扩大两倍，所以用于分离判断时不必先归一化。复用Vector3.Dot，不要用Vector3的逐分量比较来代替一维投影区间比较。

## 4. TODO 16.3 单轴分离

设两个盒中心差D=CB-CA，沿L的中心间隔为：

```text
d = abs(D·L)
```

一维区间分离等价于：

```text
d > rA(L)+rB(L)
```

找到一条这样的轴，就能证明盒子分开。只在某一轴重叠，不能证明整个三维盒相交。

本节IsSeparatedOnAxis的具体数值契约：

1. 若L.SqrMagnitude()<=1e-12，返回false，表示该退化轴没有提供分离证据。
2. 否则采用 `d > rA+rB+1e-5*L.Magnitude()` 判断分离。

1e-5是世界长度容差，乘|L|确保尺度匹配；如果缩放测试轴，容差也必须同步缩放。边界恰接触及容差内微小间隙会按相交处理，这是一种教学用数值近似，不是精确几何结论。近乎平行的边叉积也可能被小轴阈值跳过，本课不扩展成所有尺度都可靠的生产碰撞库。

零轴通常来自两条平行边的叉积；不要归一化零向量，更不能因某个叉积为零就直接宣布两盒不相交。只是跳过这一条候选轴，继续检查其他轴。

## 5. TODO 16.4 完整SAT与15条候选轴

SAT的含义：对两个凸体，如果能找到一个方向，使它们沿该方向的投影区间分离，则不相交；若相交，任何方向上的投影都无法分离。

OBB无需尝试无限多个方向，以下15条候选轴足够完成精确数学下的盒体判断：

| 来源 | 候选轴 | 数量 |
| --- | --- | --- |
| A的面法线 | A.AxisX、A.AxisY、A.AxisZ | 3 |
| B的面法线 | B.AxisX、B.AxisY、B.AxisZ | 3 |
| 双方边方向叉积 | A.Axis[i] × B.Axis[j]，i,j各为0/1/2 | 9 |

每个盒的相对面法线只有符号差，abs使其可合并为3条。叉积轴同时垂直于双方某对边方向，能识别边与边之间的分离；只测试6条面法线会漏掉这种情况。

实现Intersects时可用两个长度3的轴数组：先检查双方6条轴，再双重循环产生9条叉积轴。每条交给IsSeparatedOnAxis；发现分离立即返回false，全部检查完才返回true。复用已有`StudyNotes.Homework.Math.CrossProduct.CrossMath.Cross`。

本节不要求展开高性能15条公式，不新增SAT接口层。AABB的三个世界轴是特殊情况：盒轴都与世界坐标轴平行时，许多候选轴重复或为零。任意旋转后不能继续只看世界XYZ。

### 专门检查遗漏叉积的反例

```text
A: 中心(0,0,0)，半尺寸(1.5,0.25,0.25)，Identity
B: 中心(1.3,0.9,0.6)，同半尺寸，绕(1,1,1)轴转45度
```

双方6条面法线的投影都重叠。但L=A.AxisX×B.AxisX约为(0,0.310617,0.505879)，沿此轴中心间隔约0.583083、半径和约0.408248，间隙约0.174835，大于容差，因此不相交。

这些数值按本项目四元数约定独立计算并用float精度复核；你不需要手算这个案例。测试提供固定几何输入，用来确认9条叉积轴确实被检查，而不是为了制造某个特定返回值。
