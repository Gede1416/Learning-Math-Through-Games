## 1. 教材公式和本课契约

《3D Math Primer》作者在线版[附录A.9与A.12](https://gamemath.com/book/geomtests.html)给出射线参数式、射线平面与球面求交。核心参数式为：

```text
P(t) = O + tD
```

O是起点，D是方向，P(t)是点。作者球体例子使用单位方向，本课为练习参数与距离的区别，采用可非单位方向的一般二次方程；下面给出代入推导和明确的接口边界。

本节射线半无限：t>=0。无限直线可包含负t，有限枪线则还需要实际距离不超过range。本节的t既不是上一课的时间进度，也不默认限制到[0,1]。

```text
距离 = |P(t)-O| = t*|D|       // t>=0
```

只有|D|=1时t才等于距离。比如O=(0,0,0)，D=(0,0,2)，t=3，点为(0,0,6)，距离6；把D改为(0,0,1)，同一个点的t变成6。方向长度变了，几何射线路径可以相同，参数却变化。

三个公共工具位于`MathLibrary/RayIntersections.cs`，命名空间`StudyNotes.MathLibrary.Geometry`；复用已有Vector3和`StudyNotes.Homework.Math.DotProduct.VectorMath.Dot`。输入方向保证非零有限、球半径>0、平面法线为单位向量，不要求广泛输入校验或大世界数值优化。

两个Try方法命中返回true并写t；失败返回false且t=0。**必须先判断bool**：失败的0不是交点，而成功的t=0可以表示起点就在表面。

## 3. TODO 14.2 射线与双面平面

平面用一点Q和法线n定义：

```text
n·(P-Q) = 0
```

代入P=O+tD并展开：

```text
n·(O-Q) + t(n·D) = 0
t = n·(Q-O) / (n·D)
```

实现步骤：

1. 先令输出t=0，计算denominator=Dot(n,D)。
2. 若abs(denominator)<=1e-6*|D|，返回false。本节将近似平行视为没有可用的唯一交点；法线单位化使阈值对应方向夹角。该阈值是工程选择。
3. 计算候选参数。若候选t<0，交点在枪口后方，返回false。
4. 否则把候选参数写入out t，返回true，允许t=0。

本课是双面平面：翻转n后分子分母一起变号，t不变。不要只接受n·D<0，那是另一个单面契约。

平行有两种情况：不在平面上没有交点；整条射线在平面内有无穷交点。本方法要求唯一交点，所以两者都返回false。不要直接除零，也不要把平行时的候选NaN当成功。

枪口(0,2,0)，D=(0,-1,0)，地面Q=0、n=(0,1,0)，t=2，点为0。改D=(0,-2,0)，t=1，仍落在同一个点。

## 4. TODO 14.3 射线与球面

球心C、半径r的表面满足：

```text
|P-C|² = r²
```

令m=O-C，再代入P=O+tD：

```text
(m+tD)·(m+tD) = r²
(D·D)t² + 2(m·D)t + (m·m-r²) = 0

A = Dot(D,D)
B = 2*Dot(m,D)
C0 = Dot(m,m)-r*r         // C0是标量系数，C是球心，别混用
delta = B*B-4*A*C0
tNear = (-B-sqrt(delta))/(2*A)
tFar  = (-B+sqrt(delta))/(2*A)
```

A>0，所以tNear<=tFar。本节不要硬写A=1，也不要在函数内部归一化D后仍返回旧参数含义。

按以下顺序处理：

| 条件 | 结果 |
| --- | --- |
| delta<0 | false，射线所在直线没有球面交点 |
| delta=0 | 一个切点，仍需检查根是否非负 |
| tNear>=0 | 返回tNear，最近的前方表面交点 |
| tNear<0且tFar>=0 | 返回tFar，起点在球内部时可得到出口 |
| 两根均<0 | false，交点都在后方 |

起点在球面上时最近非负根是0，向内、向外都按本节契约返回0。起点严格在球内部时才取正的出口；本方法计算球面相交，不把“已在实体内部”自动当0命中。需要防止枪线自相交的最小正参数另行定义，本节不新增。

自检例子：O=0、C=(0,0,5)、r=1、D=(0,0,1)，根为4和6，应取4。D改为(0,0,2)，根为2和3，命中点仍为(0,0,4)。测试数据为普通尺度，切线用可精确表示的简单数据，不要求额外宽容地把负delta改成0。

## 5. TODO 14.4 枪线射程误判

文件：`Homework/数学/14-射线与平面球体相交/RayIntersectionLesson.cs`。`HitscanShot.TryHitSphereWithinRange`收到枪口、瞄准方向、目标球和实际射程，现有代码直接用t与range比较，故意埋了单位错误。

反例：枪口0，D=(0,0,10)，球心(0,0,10)，半径1；参数t=0.9、命中点z=9。射程4米时，比较0.9<=4会错误命中，实际9米已经越界。

修正可选一种：

- 保持原方向，比较t*|D|与range，命中点仍用原D和t。
- 先归一化方向，再用这个方向求交；此时t是距离。计算命中点也必须使用同一份归一化方向。

不要在求得旧t以后改方向重算点。射程边界包含等于range的交点；失败时hitPoint保持default，成功才输出世界命中点。球心可能在射程外而近侧球面在射程内，因此要比较交点距离，不是球心距离。

本课只检测单个球面，不排序多个目标，不处理遮挡墙或伤害系统。平面工具可用于后续鼠标拾取地面，球体工具用于简化目标检测；更复杂形状留到后续。
