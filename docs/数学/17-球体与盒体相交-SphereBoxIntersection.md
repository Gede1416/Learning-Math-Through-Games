## 1. 目标、教材与范围

游戏问题：爆炸中心离一面长墙的中心很远，但墙的近端已经进入爆炸球，为什么还没被判为命中？本节用实体最近点把球体碰撞转成距离比较，并复用此前的点积、局部坐标和平方长度。

教材依据：

- [《3D Math Primer》作者在线版，附录A](https://gamemath.com/book/geomtests.html)：A.5 Closest Point in an AABB、A.13两球相交、A.14球与AABB相交。A.5对盒内点明确写道：“this code returns the original point.” A.14先取球心的盒内最近点，再比较平方距离与平方半径。
- [《实时碰撞检测》作者目录](https://realtimecollisiondetection.net/books/rtcd/toc/)：4.3.1球球、5.1.3/5.1.4 AABB/OBB最近点、5.2.5/5.2.6球与AABB/OBB。本链接只用于核对章节，下面的OBB推导由本项目第16课的正交轴表达展开。

沿用+X右、+Y上、+Z前，列向量；Y+90°使+X→-Z、+Z→+X。所有球心、查询点、盒中心和盒轴都在同一世界空间。OBB轴仍是单位正交方向，半尺寸仍是局部长度，不支持错切或把缩放塞进轴。

本节约定：

- 球和盒都是闭实体，包含、边界接触都算相交；不是只检测两层表面相交。
- Sphere输入有限且Radius>=0，半径0是一个点。AABB沿用Min<=Max、允许零尺寸；OBB沿用正半尺寸与单位正交轴。不要求修复非法输入。
- 只算静态bool，不算撞击时间、穿透深度、最近法线或物理响应。
- 直接用`<=`比较平方量，不额外加epsilon。本节不照搬SAT中乘轴长度的容差；旋转最近点断言允许1e-4舍入误差，旋转布尔测试避开临界接触。精确接触测试使用可精确表达的轴对齐数值。
- 教材A.13/A.14以严格“小于”表述重叠；这里有意延续本项目“接触也算”的规则，使用小于等于。

盒体是凸体的一种。本节落实球与盒体这两个具体基元，不声称已经实现任意凸网格、胶囊或GJK。最近点距离法的思想还能推广，但其他形状需要各自正确的最近点算法。

## 2. TODO 17.1：AABB内最近点

文件：`MathLibrary/Aabb.cs`，新增`Vector3 ClosestPoint(Vector3 point)`。

### 参数意义表

| 符号 | 参数意义 | 类型/坐标空间 | 单位或范围 | 代码对应 |
| --- | --- | --- | --- | --- |
| P | 需要查询的点 | Vector3，世界位置 | 长度单位 | point |
| Q | 实体盒内离P最近的点，内部点可等于P | Vector3，世界位置 | 长度单位 | ClosestPoint返回值 |
| Min / Max | 盒子每轴的下界/上界，不是中心与尺寸 | Vector3，世界位置 | 每轴Min<=Max | Aabb.Min / Aabb.Max |
| Px / Py / Pz，Qx / Qy / Qz | P、Q沿世界X/Y/Z轴的坐标分量 | float，世界坐标 | 长度单位 | point.X/Y/Z，返回值.X/Y/Z |
| Minx/Miny/Minz，Maxx/Maxy/Maxz | 盒子对应世界轴的坐标边界 | float，世界坐标 | 长度单位 | Min.X/Y/Z，Max.X/Y/Z |
| v / a / b | clamp的待限制值/下界/上界 | float，标量 | 三者同单位，a<=b | Math.Clamp(value,min,max) |
| \|P-Q\|² | 查询点到最近点的平方距离 | float，标量 | 长度单位²，>=0 | 两点差的SqrMagnitude() |

设查询点P，最近点Q。每个坐标独立限制到盒子的区间：

```text
Qx = clamp(Px, Minx, Maxx)
Qy = clamp(Py, Miny, Maxy)
Qz = clamp(Pz, Minz, Maxz)

clamp(v,a,b)：小于a取a，大于b取b，否则保留v。
```

可以直接用`Math.Clamp(float value, float min, float max)`，不必另写公共Clamp工具。

为什么三个轴可以独立处理？

```text
|P-Q|² = (Px-Qx)² + (Py-Qy)² + (Pz-Qz)²
```

盒子的三个坐标约束互不耦合，逐项取最小值，和也最小。对实体盒而言，P已在内部时Q=P、距离0，不能强行把它推到某个面上。

例：游戏触发盒`[-1,1]³`，P=(3,-2,0.5)，Q=(1,-1,0.5)。如果P=(0.25,-0.5,0.75)，Q保持不变。返回的是一个位置，不是从P指向盒子的方向。

## 3. TODO 17.2：OBB内最近点

文件：`MathLibrary/Obb.cs`，新增`Vector3 ClosestPoint(Vector3 point)`。无需求通用逆矩阵，也无需新增四元数方法。

### 参数意义表

| 符号 | 参数意义 | 类型/坐标空间 | 单位或范围 | 代码对应 |
| --- | --- | --- | --- | --- |
| P / Q | 查询点/盒内最近点 | Vector3，世界位置 | 长度单位 | point / ClosestPoint返回值 |
| C | 本小节的OBB中心，不是球心 | Vector3，世界位置 | 长度单位 | Obb.Center |
| D=P-C | 从盒中心指向查询点的位移，不是单位方向 | Vector3，世界向量 | 长度单位，不归一化 | point-Center |
| u0 / u1 / u2 | 盒子局部X/Y/Z轴在世界中的方向 | Vector3，世界方向 | 无量纲，长度1且两两正交 | AxisX / AxisY / AxisZ |
| hx / hy / hz | 沿局部X/Y/Z轴的半尺寸，不是完整宽高深 | float，局部轴长度 | 长度单位，各分量>0 | HalfExtents.X/Y/Z |
| d0 / d1 / d2 | D沿三个盒轴的带符号投影，尚未限制 | float，局部坐标分量 | 长度单位，可超出半尺寸 | Vector3.Dot(D,对应盒轴) |
| s0 / s1 / s2 | 最近点沿三个盒轴的带符号偏移，已限制 | float，局部坐标分量 | 分别在[-hx,hx]、[-hy,hy]、[-hz,hz] | 对d0/d1/d2分别clamp后的值 |

下标0/1/2依次对应局部X/Y/Z，不是时间或插值进度；同一个下标的u、d、s必须配对。

复习第16课的盒内点表达：

```text
Q = C + s0*u0 + s1*u1 + s2*u2
-hx<=s0<=hx，-hy<=s1<=hy，-hz<=s2<=hz
```

s0/s1/s2是沿三个单位盒轴的带正负距离，单位与半尺寸相同，不是0到1的插值参数。

先把点相对于盒中心的位移投到局部轴：

```text
D = P-C
d0 = dot(D,u0)
d1 = dot(D,u1)
d2 = dot(D,u2)
```

因为u0/u1/u2单位正交，有`D=d0*u0+d1*u1+d2*u2`，且：

```text
|P-Q|² = (d0-s0)² + (d1-s1)² + (d2-s2)²

s0 = clamp(d0,-hx,hx)
s1 = clamp(d1,-hy,hy)
s2 = clamp(d2,-hz,hz)
Q  = C + s0*u0 + s1*u1 + s2*u2
```

这里仍是独立最小化三个平方项。不要将D归一化，否则会丢失距离；不要直接clamp世界X/Y/Z到局部半尺寸；最后要加回世界中心C。

正面例子：一段旋转墙中心C=(3,-2,5)，Y+90°，半尺寸(2,1,0.5)。它的长轴沿世界-Z，短轴沿世界+X。查询P=(3,-2,7.5)时，最近点约为(3,-2,7)，距离0.5，而不是沿世界X取半宽2。

### 参数意义表

| 符号 | 参数意义 | 类型/坐标空间 | 单位或范围 | 代码对应 |
| --- | --- | --- | --- | --- |
| C0 / C1 | 当前球/另一个球的中心 | Vector3，世界位置 | 长度单位 | Center / other.Center |
| r0 / r1 | 当前球/另一个球的半径，不是直径 | float，标量 | 长度单位，>=0 | Radius / other.Radius |
| \|C1-C0\|² | 两个球心的平方距离 | float，标量 | 长度单位²，>=0 | 两球心差的SqrMagnitude() |
| (r0+r1)² | 两个半径先相加、再平方得到的阈值 | float，标量 | 长度单位²，>=0 | 半径和的平方 |

这里的下标0/1只区分两个球，不表示局部轴编号。

先从两球中心连线理解：如果两中心的距离不超过两个半径之和，两实体就有公共点。复用`Vector3.SqrMagnitude()`，比较：

```text
|C1-C0|² <= (r0+r1)²
```

注意右边是“先加再平方”，不是`r0²+r1²`；也不能左边平方、右边不平方。半径非负，所以平方不会改变比较顺序，并省去平方根。同中心或一个球包住另一个也算相交，不能要求两个球面必须相交。

例：游戏中两段圆形伤害区，半径2和1、中心距离3，恰好接触，返回true。零半径球只在点属于另一个实体时相交。

## 5. TODO 17.4/17.5：球与盒体相交

在Sphere中新增`Intersects(Aabb box)`和`Intersects(Obb box)`，分别复用各盒的最近点方法。

### 参数意义表

| 符号 | 参数意义 | 类型/坐标空间 | 单位或范围 | 代码对应 |
| --- | --- | --- | --- | --- |
| C | 本小节的球心，不是第3节的OBB中心 | Vector3，世界位置 | 长度单位 | Sphere.Center |
| r | 当前球的半径 | float，标量 | 长度单位，>=0 | Sphere.Radius |
| box | 被测试的实体盒，不只是盒子表面 | Aabb或Obb，世界空间 | 沿用第1节的合法输入约束 | Intersects的box参数 |
| Q | box中离球心C最近的点 | Vector3，世界位置 | 长度单位 | box.ClosestPoint(Center)的返回值 |
| \|C-Q\|² | 球心到实体盒的最小平方距离 | float，标量 | 长度单位²，>=0 | 球心与Q之差的SqrMagnitude() |
| r² | 半径平方，即平方距离的比较阈值 | float，标量 | 长度单位²，>=0 | Radius乘自身 |

```text
Q = box.ClosestPoint(球心C)
相交条件：|C-Q|² <= r²
```

为什么充分且必要？Q已是整个实体盒中离球心最近的点。如果Q都在球外，其他盒内点更远，两个实体无公共点；如果Q在球内或球面上，Q本身就是公共点。球心在盒内时最近距离为0，所以小球完全藏在盒内也会命中。

两个重载是使用不同盒类型的同一数学规则，不需要复制clamp代码，也不需要调用上一课的OBB-OBB SAT。

反例：把盒子的每个区间向外扩大r，再用球心ContainsPoint，只能作保守初筛。角落会多包出不属于真实圆角范围的区域；初筛通过不代表精确球盒相交。这也不是把目标一律简化为中心点或包围球的理由：简化方法会改变被测试的实体。
